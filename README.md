# DnsZapret

Программа для Windows: zapret, NextDNS и локальный TG WS Proxy в одном консольном меню и трее.

## Скачать

**[Скачать последнюю версию для Windows x64](https://github.com/Nusferatyxgod/DnsZapret/releases/latest/download/DnsZapret-win-x64.zip)**

Распакуй весь ZIP и запусти `DnsZapret.exe`. Установка .NET, аккаунт GitHub, GitHub CLI и токены GitHub не нужны.

## Начало работы

1. Запусти подбор стратегии через пункт **1**, затем включи выбранную стратегию пунктом **2**.
2. Для NextDNS укажи **ID своего профиля из шести символов** в **5 → 2**. **5 → 3** применяет DNS с сохранением прежних настроек; **5 → 4** возвращает их.
3. Для Telegram Desktop: **10 → 1** устанавливает официальный TG WS Proxy, **10 → 2** подключает Telegram, **10 → 4** включает тихий запуск прокси вместе с DnsZapret.
4. Чтобы всё запускалось при входе в Windows: **6 → 1** — общий автозапуск. После установки движка и TG-прокси это включает приложение в трее, последнюю сохранённую стратегию и тихий прокси. Консоль при входе в Windows не открывается. **6 → 2** отключает весь автозапуск. При переходе с 0.9.2 и старше один раз повтори **6 → 1**.
5. **0** закрывает меню и оставляет приложение в трее. Полный выход — через меню значка возле часов.

Настройка движка, DNS и автозапуска запрашивает UAC. Профиль NextDNS каждый пользователь подключает самостоятельно. Облачная автоматизация пользователю для обновлений программы не нужна.

## Обновления

Программа проверяет версии при запуске и каждые 6 часов. В трее появится уведомление. Открой **U — обновления и откат**, проверь версии и выбери компонент для установки. Предыдущая версия сохраняется для отката. Обновление самого приложения скачивается из этого публичного репозитория; движок и TG-прокси — из официальных релизов Flowseal с проверкой SHA-256 и совместимости пакета.

Для перехода с версии **0.9.1 и старше** скачай публичный ZIP вручную один раз: их обновлятор обращался к закрытому каналу. Дальнейшие обновления с **0.9.2** работают без авторизации.

## Личные данные

Готовая сборка не содержит API-ключей автора, пользовательского профиля NextDNS, конфигов TG-прокси и журналов. Ключи NextDNS для скачивания и обновления программы не нужны. Локальная конфигурация TG создаётся на ПК пользователя. На ПК, где приложение уже запускалось, оно использует сохранённые настройки из `%LOCALAPPDATA%\DnsZapret`.

Этот репозиторий содержит готовые релизы и документацию. Секреты и задания обновления DNS владельца здесь не размещаются.
