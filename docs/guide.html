Программа подбирает стратегию zapret на твоём ПК и помогает подключить NextDNS. Команды писать не надо: вводи номер пункта и нажимай Enter.

Windows 11 · x64 · установка .NET не нужна

1. Открой программу

Распакуй DnsZapret-win-x64.zip в отдельную папку. Запусти DnsZapret.exe. Сохрани рядом файл guide.html — это инструкция.

При первом запуске появится мастер. Ответь д, чтобы начать, или н, чтобы перейти в меню. Для установки движка, запуска тестов и изменения DNS Windows покажет обычный запрос прав администратора.

Если у тебя уже работает другая сборка zapret, сначала останови её через её окно или службу. Приложение не останавливает чужие экземпляры.

2. Создай профиль NextDNS

  1. Введи 5 → 1 в меню и зарегистрируйся на my.nextdns.io, чтобы профиль сохранился.
  2. На вкладке «Настройка» / Setup найди ID: шесть цифр или букв от a до f. Например, a1b2c3.
  3. Введи 5 → 2, вставь свой ID и нажми Enter. Программа покажет твой URL DoH.
  4. Введи 5 → 3, выбери адаптер с интернетом (Ethernet или Wi-Fi), подтверди применение и запрос Windows. Прежние настройки сначала сохранятся.
  5. Введи 7. Проверь статус NextDNS, протокол DoH и профиль. Дополнительно открой test.nextdns.io в браузере.

Если в браузере уже выбран другой безопасный DNS, скопируй URL из 5 → 2 и укажи его в настройках безопасного DNS браузера. После этого повтори проверку.

В приложении нужен только ID. API-ключ NextDNS понадобится только для облачного обновления правил — он хранится в GitHub Secrets.

3. Доверь подбор программе

  1. Введи 1 и подтверди запуск подбора. Программа скачает официальный выпуск Flowseal 1.10.3, если он ещё не установлен, и проверит SHA-256 архива.
  2. В выборе режима нажми Enter для быстрого подбора: до 6 стратегий и режим без zapret. Адреса проверяются параллельно; повторная проверка и скачивания — только у двух финалистов (около 4 МиБ). Обычно это около минуты, но время зависит от сети. Введи 2 для полного перебора всех 22 стратегий. Для отмены нажми Ctrl+C именно в окне проверки.
  3. Программа применит лучший подтверждённый результат. Приоритет — Telegram Web, ChatGPT и TikTok; затем остальные адреса, скорость и задержка. Если прямое подключение лучше, будет выбран режим без zapret.
  4. Введи 8, чтобы посмотреть таблицу и результаты адресов. Затем проверь видео YouTube и звонки Discord вручную.
  5. Чтобы выбрать стратегию самому, введи 4. Если движок работал, программа переключит его. Если был выключен, выбор сохранится для следующего запуска через 2.
  6. Для запуска вместе с Windows сначала установи TG WS Proxy (10 → 1) и подключи Telegram (10 → 2), затем введи 6 → 1: трей, последняя выбранная стратегия и тихий TG-прокси включаются вместе. После смены стратегии повторять настройку не нужно.

2 — включить выбранную стратегию. 3 — выключить. 6 → 2 — убрать автозапуск. Выход из меню (0) оставляет движок работающим.

В targets.json рядом с EXE находятся 13 HTTPS-адресов YouTube, Discord, Steam, Telegram Web, ChatGPT, TikTok, Google и GitHub. Можно добавить свои записи; required: true отмечает приоритет. Это не проверка всех доменов интернета. Мбит/с — скорость файла Cloudflare, а не YouTube. Статус HTTP означает, что соединение есть, но ответ сервера не подтверждает доступ. Например, ChatGPT может запросить проверку в браузере; HTTP 403 не считается OK. Если все приоритетные сервисы не прошли, программа покажет предупреждение.

Telegram Desktop: введи 10 → 1, подтверди установку официального TG WS Proxy. В его первом окне подтверди подключение Telegram или выбери значок в трее → «Открыть в Telegram». В нашей программе 10 → 2 тоже откроет настройку подключения в Telegram. Для остановки — значок прокси в трее → «Выход». Автозапуск прокси включается в его собственных настройках. Эта часть работает отдельно от Telegram Web.

В первой версии Game Filter выключен. Нет обещаний максимальной скорости Telegram, 4K без задержек или отсутствия реакции любого античита.

Трей и тихий запуск Telegram-прокси

DnsZapret остаётся возле часов после закрытия меню. Двойной щелчок по значку открывает меню; правая кнопка показывает настройки. Выбери «Запускать DnsZapret сразу в трее», чтобы при следующем обычном запуске не открывалась консоль.

Установи TG WS Proxy через 10 → 1, один раз подключи Telegram через 10 → 2, затем включи тихий запуск через 10 → 4. При следующих запусках DnsZapret установленный прокси будет запускаться без приветственного окна и открытия Telegram. Уже работающий прокси повторно не запускается; отсутствующий автоматически не скачивается. Собственные ошибки прокси могут отображаться его окнами.

6 → 1 включает общий автозапуск с подтверждением UAC: при входе в Windows запускаются только трей, сохранённая стратегия zapret и тихий TG-прокси. 6 → 2 отключает весь автозапуск. Это также доступно в трее → Настройки → Автозапуск Windows. При переходе со старых версий один раз повтори 6 → 1. Движок запускается с повышенными правами, трей и прокси — с обычными. Ошибка одного компонента показывается уведомлением и не прерывает запуск остальных. Автоматического скачивания при входе в Windows нет.

Закрыть окно меню — свернуть DnsZapret в трей. Правая кнопка по значку → «Выход из DnsZapret» — остановить его zapret и TG WS Proxy, закрыть меню и завершить приложение. Чужие установки не затрагиваются. Для старого движка при первом выходе может потребоваться UAC. При занятой операции или ошибке остановки значок остаётся доступным. Сохранённая настройка DNS и автозапуск Windows при выходе не удаляются.

Обновления приложения, zapret и Telegram

Открой U — обновления и откат в главном меню. 1 только проверяет версии. 2/4/6 устанавливают новую версию zapret/TG/DnsZapret с подтверждением и UAC. 3/5/7 возвращают предыдущую. Работающий компонент перезапустится; старые файлы сохранятся.

Проверяется точный официальный релиз и SHA-256. Стратегии разбираются из нового пакета, пользовательские списки и конфигурация TG сохраняются. При ошибке запуска выполняется откат. R перезапускает установленную версию самого DnsZapret. Если zapret работал, подтверди UAC для его повторного запуска. При отмене включи его пунктом 2.

Трей проверяет версии при старте и каждые 6 часов. Автоматической установки нет; уведомления выключаются в настройках трея. Все обновления скачиваются из публичных официальных релизов. Аккаунт GitHub, GitHub CLI и токены не нужны.

4. Как приходят обновления

Разработчик проверяет новые версии Flowseal и совместимость стратегий, затем выпускает сборку в публичном репозитории DnsZapret. Программа уведомит о доступном обновлении. Открой U и выбери компонент.

Пользователю не нужны своё облако, репозиторий, GitHub CLI или токен GitHub. ID профиля NextDNS из пункта 5 → 2 относится к настройке DNS, а не к каналу обновлений программы. Обновление правил внутри личного профиля NextDNS — отдельная операция; готовая программа не использует API-ключ автора и не обновляет чужой профиль автоматически.

5. Если что-то сломалось

Интернет пропал после DNS: введи 5 → 4. При ошибке применения программа сама пытается восстановить прежние настройки. Если восстановление не удалось, копия сохраняется для повторной попытки.

Сервис не открывается: повтори подбор через 1 или выбери другую стратегию через 4. HTTP-ответ сайта не проверяет видео, звонки или скорость загрузки файлов.

Не запускается движок: введи 9 → 3 и открой app.log. Проверь, не запущена ли другая копия winws. Программа не меняет антивирус, исключения, firewall и hosts.

Полностью отключить: 6 → 2 (убрать автозапуск) → 3 (выключить) → 5 → 4 (вернуть DNS). Для удаления файлов движка после остановки можно вручную удалить C:\ProgramData\DnsZapret\engine.

Можно передать другу?

Да: передай весь ZIP или ссылку на последний публичный релиз DnsZapret. В архиве нет личных настроек, логов и API-ключей владельца. Друг подключает собственный профиль NextDNS и настраивает Telegram.

Проверка и установка обновлений работают через U без входа в GitHub. На ПК, где программа уже использовалась, сохранённые настройки подхватятся из AppData.

Codex / ChatGPT: не загружается аккаунт

Пункт 7 проверяет маршрут к API аккаунтов без токенов и cookie. HTTP 401 означает лишь ответ защищённого API, а не успешный вход. HTTP 403 «Unable to load site» означает отказ сервера на текущем маршруте/IP: главная страница при этом может открываться. zapret не меняет внешний IP. Проверь выходной сервер DNS-переадресации или другой доступный маршрут. Диагностика не меняет DNS и сессию Codex.

Исходные проекты: noVibe/DnsConf и Flowseal/zapret-discord-youtube. Наша программа — отдельная оболочка. Запускаемые версии закреплены в проекте.
